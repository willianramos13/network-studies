# network-studies
Laboratórios de Redes, Mikrotik, Linux e Wireshark.

Repositório criado para documentar minha jornada de aprendizado em:

- Redes TCP/IP
- Mikrotik
- Linux
- Wireshark
- Roteamento
- VLAN
- NAT
- OSPF

## Laboratórios

### Dia 03
Captura de pacotes ICMP utilizando Wireshark.

### Dia 04
Criação de topologia com 3 roteadores Mikrotik e rotas estáticas.

### Dia 05
Diagnóstico de falhas após remoção de rota estática.

### Dia 06
Estudo de ARP, Broadcast e Gateway utilizando captura de pacotes.
